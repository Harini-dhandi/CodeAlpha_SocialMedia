# CodeAlpha Social Media Platform

A mini social media web application developed as part of the CodeAlpha Full Stack Development Internship – Task 2.

## 📌 Project Overview

This project is a simple social media platform where users can create accounts, create posts, interact with posts, comment, like posts, and follow other users.

## 🚀 Features

- User Registration
- User Login
- User Profiles
- Create Posts
- View Posts
- Like / Unlike Posts
- Add Comments
- Follow / Unfollow Users
- Followers and Following
- Data Storage

## 🛠️ Technologies Used

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js

### Database / Storage
- JSON-based data storage
